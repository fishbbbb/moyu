# 墨鱼阅读器 · 启动指南

本文档说明如何在本地安装依赖并启动 **Electron 桌面端**（`desktop/`）。更完整的架构与 IPC 说明见 [开发手册.md](./开发手册.md)。

---

## 1. 项目简介

墨鱼阅读器是一款基于 **Electron + Vite + React** 的跨平台桌面阅读应用，主要能力包括：

- 导入本地 **TXT / EPUB** 到书架
- 桌面 **Overlay 阅读条**（置顶透明、自动滚动、快捷键）
- 网页内容提取与导入（开发中/部分能力）

应用代码位于仓库的 `desktop/` 目录，**所有启动命令均在该目录下执行**。

## 3. 首次安装

在终端进入 `desktop` 目录并安装依赖：

```bash
cd desktop
npm install
```

### 3.1 `postinstall` 会自动做什么

`npm install` 完成后会触发 `postinstall`，依次执行：

1. **`ensure-electron.mjs`** — 确保 Electron 二进制已下载
2. **`rebuild:native`** — 针对当前 Electron 版本重编译 `better-sqlite3`

因此首次安装通常比纯前端项目更慢，属正常现象。

### 3.2 国内网络：Electron 下载加速

若 Electron 下载失败或极慢，可先设置镜像再安装：

```bash
export ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
npm install
```

项目脚本 `scripts/ensure-electron.mjs` 也会尝试使用上述镜像。

## 4. 开发模式启动（最常用）

```bash
cd desktop
npm run dev
```

### 4.1 启动后会发生什么

`npm run dev` 通过 `concurrently` 并行启动三个进程：

| 进程 | 说明 |
|------|------|
| **Vite** | 前端开发服务器，地址 `http://127.0.0.1:5173` |
| **tsc --watch** | Electron 主进程 TypeScript 监听编译，输出到 `dist-electron/` |
| **Electron** | 等待 5173 端口就绪后启动桌面应用 |

环境变量 `ELECTRON_DEV=1` 表示开发模式，窗口会加载 Vite 热更新页面而非打包后的静态资源。

### 4.2 启动成功的标志

- 终端无报错，Vite 显示 `Local: http://127.0.0.1:5173/`
- 弹出 **主窗口**（书架 / 导入 / 设置）
- 导入书籍并加载章节后，可出现 **Overlay 阅读条** 窗口

### 4.3 停止开发服务

在运行 `npm run dev` 的终端按 `Ctrl + C`。`concurrently -k` 会一并结束子进程。

---

## 5. 启动后快速验证

1. 在主窗口选择一本 **TXT** 或 **EPUB** 导入
2. 在书架中选中书籍，点击章节 **「加载到阅读条」**
3. 确认桌面出现透明阅读条，可用工具栏播放/暂停、翻页
4. 老板键：`⌘ + Shift + X`（macOS）或 `Ctrl + Shift + X`（Windows）显示/隐藏阅读条

## 6. 其他常用命令

### 6.1 生产构建（非安装包）

```bash
cd desktop
npm run build
```

产出：

- `dist/` — Vite 打包的前端资源
- `dist-electron/` — 编译后的 Electron 主进程代码

> 当前仓库以 MVP 为主；生成 `.dmg` / `.exe` 安装包需另行接入 electron-builder，见 [开发手册.md 第 8 节](./开发手册.md)。

### 6.2 原生模块重编译

依赖或 Electron 版本变更后，若出现 `better-sqlite3` 相关报错：

```bash
cd desktop
npm run rebuild:native
```

### 6.3 自测脚本

```bash
cd desktop
npm run selftest:chapters          # 章节拆分逻辑
npm run selftest:web-import-core   # 网页导入核心
npm run selftest:web-import        # 网页导入样本集
```

## 7. 常见问题

### Q1：`better-sqlite3` 编译失败

**原因**：缺少 Python 或系统编译工具链。

**处理**：

```bash
# macOS：确认 CLI Tools 已装
xcode-select --install

cd desktop
npm run rebuild:native
```

### Q2：端口 5173 被占用

Vite 配置了 `strictPort: true`，5173 被占用时 dev 会直接失败。

**处理**：关闭占用该端口的进程，或修改 `vite.config.ts` 中的 `server.port`（需同步调整 `package.json` 里 `wait-on tcp:5173`）。

### Q3：Electron 窗口空白

- 确认 Vite 已启动且无编译错误
- 查看终端中 `dist-electron/main.js` 是否已生成
- 可手动触发主进程编译：`npx tsc -p tsconfig.node.json`

### Q4：Overlay 打开但无内容

需先在主窗口 **导入书籍** 并 **加载章节到阅读条**；空态时 Overlay 会显示占位提示。

### Q5：修改主进程代码不生效

主进程代码在 `electron/` 下，由 `tsc --watch` 编译。保存后需 **重启 Electron 窗口**（关闭应用后重新 `npm run dev`，或在 dev 终端重启 Electron 子进程）。

渲染进程（`src/`）由 Vite 热更新，一般无需重启。

## 8. 目录速查

```
desktop/
├── electron/           # 主进程、预加载、数据库
│   ├── main.ts
│   ├── preload.ts
│   └── db.ts
├── src/                # React 渲染进程（主窗 / Overlay / 工具栏）
├── scripts/            # 启动与自测脚本
├── dist/               # build 产出（前端）
├── dist-electron/      # build / dev 产出（主进程）
├── package.json        # 脚本入口
└── vite.config.ts      # Vite 配置（端口 5173）
```
